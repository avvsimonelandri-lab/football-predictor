GUIDA GITHUB — come funziona questo repository
==============================================

Repository:          https://github.com/avvsimonelandri-lab/football-predictor
Versione telefono:   https://avvsimonelandri-lab.github.io/football-predictor/
Ultima versione exe: https://github.com/avvsimonelandri-lab/football-predictor/releases/latest

COSA FA DA SOLO
* "Pagina telefono" (.github/workflows/site.yml): ogni 4 ore scarica i dati, aggiorna
  lo storico pronostici (state/storico.json) e pubblica la pagina per il telefono.
* "Crea programma Windows" (.github/workflows/build.yml): quando cambia il numero in
  version.py costruisce FootballPredictorPro.exe su Windows, lo prova (aggiornamento
  dati senza finestra) e lo pubblica come release vX.Y. Il programma sul PC lo propone
  e lo installa da solo (Impostazioni -> campo GitHub: avvsimonelandri-lab/football-predictor).

NUOVE VERSIONI
Le pubblica Claude: modifica il codice, aumenta il numero in version.py e carica tutto.
Si può anche fare a mano: scheda Actions -> "Crea programma Windows" -> Run workflow.

RISULTATI IN GIORNATA ANCHE SUL TELEFONO (facoltativo)
Settings -> Secrets and variables -> Actions -> New repository secret
Nome: FDORG_KEY   Valore: la chiave gratuita di football-data.org

NOTE
* Il repository è pubblico: codice e pagina sono visibili a chi ha l'indirizzo (la pagina
  non viene indicizzata dai motori di ricerca). Le chiavi nei "Secrets" restano segrete.
* GitHub sospende i lavori programmati dopo 60 giorni senza attività: i salvataggi dello
  storico contano come attività; se la pagina smette di aggiornarsi: Actions ->
  "Pagina telefono" -> Run workflow.
* Sul telefono: apri la pagina e scegli "Aggiungi a schermata Home".
