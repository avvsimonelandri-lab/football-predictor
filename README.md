# Football Predictor Pro

Pronostici statistici di calcio (modello Dixon-Coles con forma recente, fattore campo,
xG stimati dai tiri e stima combinata con le quote dei bookmaker).

- **Programma Windows**: scarica `FootballPredictorPro.exe` dall'ultima [release](../../releases/latest).
- **Versione per telefono**: https://avvsimonelandri-lab.github.io/football-predictor/ (aggiornata ogni 4 ore).

Istruzioni: `LEGGIMI.txt` e `GUIDA_GITHUB.txt`.

Stime statistiche, non certezze. Il gioco è vietato ai minori e può causare dipendenza.
